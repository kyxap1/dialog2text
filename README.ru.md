# Расшифровка диалогов на Mac (Apple Silicon)

Превращает видео или аудиозапись в текст, где у каждой реплики подписан говорящий:

```
[SPEAKER_00]: давай начнём со второго пункта повестки
[SPEAKER_01]: хорошо, я тогда покажу цифры за прошлый месяц
```

Всё считается на вашем Mac — ничего никуда не отправляется.

По умолчанию распознаётся русская речь (как поменять — в разделе [Настройки](#настройки)).

English version: [README.md](README.md)

## Что нужно

- Mac с чипом Apple Silicon (M1 или новее).
- Около 10 ГБ свободного места на диске (модели распознавания большие).
- Бесплатный аккаунт на Hugging Face — он нужен один раз, чтобы скачать модель распознавания говорящих.

## Установка (один раз)

**1. Установите Homebrew** (пропустите, если он уже есть). Откройте программу «Терминал» и вставьте туда:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

**2. Получите токен Hugging Face:**

- Зарегистрируйтесь: https://huggingface.co/join
- Откройте https://huggingface.co/pyannote/speaker-diarization-community-1 и примите условия использования модели (в первый раз появится форма).
- Откройте https://huggingface.co/settings/tokens → **Create new token** → тип **Read** → скопируйте токен (длинная строка, начинается на `hf_`).

**3. Запустите установку:** дважды щёлкните по файлу `install.command` в этой папке.

Откроется окно Терминала, установка пойдёт сама. В конце скрипт попросит токен — вставьте его и нажмите Enter. Во время вставки на экране ничего не появится, это нормально: так токен не подсматривают.

Весь шаг занимает несколько минут. Если macOS откажется запускать файл («неизвестный разработчик») — щёлкните по нему правой кнопкой → **Открыть** → **Открыть**.

Привыкли к Терминалу? Команда `./install.sh` делает то же самое.

## Как пользоваться

1. Скопируйте видео или аудио в папку `input` (mp4, mov, mp3, m4a, wav — всё, что читает ffmpeg).
2. Дважды щёлкните по `run.command` (или запустите `./run.sh` в Терминале).
3. Подождите. Самый первый запуск ещё и скачивает около 5 ГБ моделей, поэтому он гораздо медленнее последующих.

Результаты появятся в папке `output/<имя файла>/`:

| Файл   | Что это                                                     |
|--------|-------------------------------------------------------------|
| `.txt` | обычный текст расшифровки с подписями говорящих — начните с него |
| `.srt` | субтитры, их понимает любой видеоплеер                       |
| `.vtt` | субтитры для веб-плееров                                     |
| `.tsv` | таблица с временными метками, открывается в Excel/Numbers    |
| `.json`| все детали, для дальнейшей обработки                         |

Чтобы расшифровать один конкретный файл, а не всю папку `input`:

```bash
./run.sh ~/Desktop/интервью.mp4
```

## Настройки

Настройки — в начале файла `run.sh`. Откройте его любым текстовым редактором и поменяйте значение после `:-`:

| Настройка    | По умолчанию | Что значит                                                      |
|--------------|--------------|-----------------------------------------------------------------|
| `LANGUAGE`   | `ru`         | язык записи: `en`, `de`, `fi`, … (`en` — английский)              |
| `SPEAKERS`   | `2`          | сколько человек говорит в записи                                 |
| `MODEL`      | `large-v3`   | `medium` или `small` работают быстрее, но менее точно             |
| `FORMAT`     | `all`        | поставьте `txt`, если нужен только текст без субтитров            |
| `OUTPUT_DIR` | `output`     | куда складывать результаты                                       |

Можно задать их и на один запуск, ничего не редактируя:

```bash
SPEAKERS=3 LANGUAGE=en ./run.sh
```

## Если что-то не так

- **Сообщения про `libtorchcodec`, `Lightning automatically upgraded…` или `No --hf_token provided`** — безвредны, расшифровка всё равно идёт. Волноваться стоит только если обработка оборвалась.
- **«Неизвестный разработчик»** при двойном щелчке — правая кнопка мыши по файлу → **Открыть** → **Открыть**.
- **`Nothing to do: the input/ folder is empty`** — файлы лежат не там; они должны быть прямо внутри папки `input`.
- **Модель распознавания говорящих не скачивается** — нет токена или не приняты условия модели. Повторите шаг 2 установки, затем удалите файл `.env` и запустите `install.command` заново, чтобы ввести новый токен.
- **Все реплики подписаны одним `SPEAKER_00`** — голоса сильно накладываются друг на друга; попробуйте указать в `SPEAKERS` реальное число участников.
- **Кончилось место на диске** — папка `models` и `~/.cache/huggingface` занимают несколько ГБ; если их удалить, они просто скачаются заново.

## Что за файлы в этой папке

| Имя                | Зачем                                                          |
|--------------------|----------------------------------------------------------------|
| `install.command`  | разовая установка, запускается двойным щелчком                   |
| `run.command`      | расшифровать всё из папки `input`, двойной щелчок                |
| `install.sh`, `run.sh` | те же два скрипта для запуска из Терминала                  |
| `requirements.txt` | точные версии Python-пакетов (проверенный рабочий набор)         |
| `.env`             | ваш токен Hugging Face — личный, не показывайте и не публикуйте  |
| `input/`, `output/`, `models/` | ваши записи, расшифровки и скачанные модели          |

Под капотом: [whispermlx](https://pypi.org/project/whispermlx/) (Whisper на Apple MLX) для распознавания речи
и [pyannote](https://huggingface.co/pyannote/speaker-diarization-community-1) для разделения говорящих.
